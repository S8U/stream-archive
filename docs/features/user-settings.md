# 사용자 설정

## 상태

- 구현 완료

## 목적

사용자마다 화면 동작을 바꿀 수 있는 개인 설정을 둔다.
첫 설정은 관리자가 일부공개(UNLISTED) 채널과 동영상을 홈·검색·사이드바에서 함께 보는 것이다.
일부공개는 링크를 아는 사람만 보는 공개 범위라 목록에는 나오지 않는다.
관리자는 자기 아카이브를 둘러볼 때 일부공개도 목록에서 보고 싶을 수 있어서 설정으로 켜고 끈다.

설정은 내 정보 창의 설정 탭에 둔다.
앞으로 설정이 늘어도 같은 탭에 줄이나 묶음을 더하면 되게 하기 위함이다.

## 설정 목록

| 키 | 화면 이름 | 기본값 | 관리자 전용 | 동작 |
|---|---|---|---|---|
| `SHOW_UNLISTED_CHANNELS` | 일부공개 채널 보기 | `false` | 예 | 사이드바 채널 목록과 홈·검색 동영상 목록에 일부공개 채널을 넣는다 |
| `SHOW_UNLISTED_VIDEOS` | 일부공개 동영상 보기 | `false` | 예 | 홈·검색·채널 동영상 목록과 채널 통계에 일부공개 동영상을 넣는다 |

두 설정은 따로 동작한다.
동영상은 채널 조건과 동영상 조건을 모두 만족해야 목록에 나온다.
예를 들어 동영상 설정만 켜면 공개 채널의 일부공개 동영상은 나오지만 일부공개 채널의 동영상은 나오지 않는다.

채널 상세 화면의 동영상 목록은 채널 조건을 보지 않는다.
채널 상세에 들어왔다면 채널 접근은 이미 따로 검증했기 때문이다.

비공개(PRIVATE)는 설정과 상관없이 목록에 나오지 않는다.

## 저장

`user_settings` 테이블에 사용자·키마다 한 행을 둔다.
값은 문자열로 저장하고, 키마다 기본값을 `UserSettingKey`에 둔다.
저장한 적 없는 설정은 기본값을 쓴다.

설정마다 컬럼을 두지 않고 키·값 행으로 둔 이유는 설정을 더할 때 테이블을 바꾸지 않기 위함이다.
`setting_key`는 DB ENUM이 아닌 VARCHAR다.
ENUM이면 키를 더해도 `ddl-auto: update`가 값 목록을 바꾸지 않아 새 키를 저장하지 못한다.

관리자 전용 설정은 관리자가 아니면 저장된 값이 있어도 기본값을 쓴다.
관리자였다가 일반 사용자가 되면 설정이 남아 있어도 적용되지 않는다.

## API

| 메서드 | 경로 | 설명 |
|---|---|---|
| `GET` | `/users/me/settings` | 적용 중인 설정 값. 비로그인이면 401 |
| `PUT` | `/users/me/settings` | 보낸 필드만 바꾼다. 관리자 전용 설정을 일반 사용자가 바꾸면 403 |

동영상 목록 응답(`GET /videos`)은 동영상과 채널의 `contentPrivacy`를 함께 준다.
화면은 이 값으로 일부공개 표시를 붙인다.

## 화면

- 내 정보 창에 프로필, 비밀번호 옆으로 설정 탭이 있다. 지금 있는 설정이 모두 관리자 전용이라 일반 사용자에게는 탭이 없다.
- 저장하면 서버 화면과 받아 둔 데이터를 모두 다시 받아 목록에 바로 반영한다.
- 일부공개 채널은 사이드바와 동영상 카드의 채널명 뒤에 링크 아이콘을 붙인다.
- 일부공개 동영상은 동영상 카드의 날짜 뒤에 링크 아이콘과 "일부공개"를 붙인다.

화면 설계는 `design/`에 있다.

## 설정 더하기

1. `UserSettingKey`에 키, 기본값, 관리자 전용 여부를 더한다.
2. `UserSettingLoadResult`와 설정 조회·수정 DTO에 필드를 더한다.
3. 설정 탭에 줄을 더한다. 성격이 다른 설정이면 묶음 소제목을 새로 둔다.

키를 없앨 때는 그 키로 저장된 행을 먼저 지운다.
